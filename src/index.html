    使用说明
    
  

  
    
    
  1. 公式模式：上半区写纯文本，数学内容用 $…$ 或 $$…$$ 包裹，下半区实时渲染并标出语法错误。
    2. 
    
  2. 习题模式：点击「＋ 添加习题」增加习题栏；左框填题号，右框写公式。导出时逐题检查，错误精确到题号。
    3. 
    
  3. 快捷输入：默认收起，点右上角 ∑ 或按 Ctrl + / 展开；点击插入，悬停可看效果与写法。分段函数、align 在「矩阵·分段」里；「自定义」里可以添加自己的按钮。
    4. 
    
  4. 自动补全：输入 $、{、(、[ 会自动成对；连续快速按两次 $ 可得到 $$…$$。
    5. 
    
  5. 主题与背景：右上角齿轮可选择主题、上传背景并调节不透明度与模糊。
    6. 
    
  6. 数据自动保存在本机浏览器里，关闭页面不会丢失。
    7.
